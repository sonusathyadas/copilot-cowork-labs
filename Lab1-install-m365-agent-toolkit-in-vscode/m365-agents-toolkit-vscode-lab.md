## Overview

### Prerequisites

| Item | Requirement |
|---|---|
| Visual Studio Code | Latest stable release |
| Microsoft 365 account | A work or organization account |


---

## Part A: Install the Microsoft 365 Agents Toolkit

### A1. Open the Extensions view

1. Launch Visual Studio Code.
2. Select **View > Extensions**, or press **Ctrl+Shift+X**. You can also select the **Extensions** icon in the activity bar.
3. The **EXTENSIONS: MARKETPLACE** pane opens.

### A2. Find and install the toolkit

1. In the search box, enter **Microsoft 365 Agents Toolkit**.
2. Select **Microsoft 365 Agents Toolkit** in the results. Its details open in the right pane.
3. Select **Install**.

**Verify:** The Agents Toolkit icon appears in the Visual Studio Code activity bar.
